## Architecture and resource lifetime review (2026-09-24)

The combined changes use the shared engine, adapter interfaces, and SDK contracts. The follow-up audit found two resource lifetime gaps in the paths used by the integrated fixes:

- Some infrastructure-only helpers disposed their platform before using its SSL/routing provider or executor. With #451's connection holds, that released the operation's SSH ownership too early. Six certificate operations failed after advancing the real pool's idle timers by six minutes. SSL issuance, renewal, verification, certificate upload, mail/webmail routing, edge verification (including its cached sweep), and recovery manifest removal now release the platform after their work settles. The process-owned fallback platform is retained. The existing cleanup mechanism remains responsible for releasing transports.
- Cloud log cleanup only set a flag. Idle SDK streams and in-flight history requests could remain connected indefinitely after a view closed; all six HTTP cancellation cases reproduced this. Each subscription now carries its own abort signal through history and both live-log sources. The existing Oblien 2.4.0 dependency is pinned and patched to pass the signal through its own transport and cancel stream readers. There is no second SSE parser or HTTP client. Source-release packaging copies the patch and manifest entry; desktop/native bundles include the patched implementation.

Verification: **400 tests passed** across 193 API/engine cases, 16 adapter cases, 19 platform stream cases, and the complete 172-test SDK suite. This includes real connection-pool timers with simulated SSH transports, real SDK requests to a local HTTP server, failure cleanup, concurrent subscribers, native engine execution, and source-release artifact checks. API/platform/adapters/SDK typechecks and builds passed, as did the native worker build. A separate source-release check generated a fresh lockfile, reinstalled with `--frozen-lockfile`, and confirmed that the installed SDK closes an idle stream on cancellation under Bun.
