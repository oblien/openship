## A complete application backend

Supabase brings Postgres together with authentication, REST APIs, realtime updates, object storage, and Studio. It suits applications that need several backend capabilities in one stack.

The template declares the service stack and its API gateway. Generated configuration keeps shared credentials consistent, while Studio provides a browser interface for working with the backend.

## Plan for the full stack

Choose a destination with capacity for all services, review the install settings, and use the resulting API URL and application keys in your frontend or backend.

Set up backups for database records and stored files. Follow the [Supabase Docker self-hosting guide](https://supabase.com/docs/guides/self-hosting/docker) for additional integrations and operating guidance.
