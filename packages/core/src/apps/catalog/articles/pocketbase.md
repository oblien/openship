## A compact backend

PocketBase puts a SQLite-backed database, authentication, realtime subscriptions, file storage, and an admin dashboard into one service. It is a useful starting point for small applications, internal tools, and prototypes.

The template provides service configuration and persistent storage. Create collections in the admin dashboard and connect your application to the deployed API.

## Keep the data in mind

The database and uploaded files belong to the persistent data directory. Configure backups before relying on the instance for important records.

Read the [PocketBase documentation](https://pocketbase.io/docs/) for collection rules, authentication, subscriptions, and the operating limitations of the installed release.
