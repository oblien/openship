## A backend that stays in sync

Convex combines a database with application functions and reactive queries. Use it for applications where the interface needs to reflect changing data, from collaborative tools to live dashboards.

The Openship template runs the backend and developer dashboard together. The backend uses a persistent volume, and the catalog declares routes for its API, HTTP actions, and dashboard.

## After deployment

Open the dashboard and use the connection information from the install flow. Point your application and Convex tooling at the deployed backend, then deploy your functions using the upstream workflow.

Review the [Convex self-hosting guide](https://docs.convex.dev/self-hosting) for the operating model and supported setup.
