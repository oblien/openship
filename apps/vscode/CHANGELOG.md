# Changelog

## 0.8.0

- Add the first Openship VS Code extension, aligned with the existing Openship release version.
- Connect to an API using a token stored in SecretStorage.
- Browse projects and deployment history; link individual workspace folders.
- Deploy remote Git branches, follow build/application logs, cancel deployments, and respond to interactive decisions.
- Open dashboard/application URLs and validate `openship.json` using the existing schema.
