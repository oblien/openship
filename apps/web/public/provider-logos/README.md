# Provider and database marks

Railway uses the [Devicon v2.16.0 mark](https://github.com/devicons/devicon/blob/v2.16.0/icons/railway/railway-original.svg)
with black fill for light surfaces; its shape is unchanged. PostgreSQL, MySQL and
MongoDB marks in `../app-logos` are unchanged from the same Devicon release.
These assets use the accompanying MIT license.

Vercel uses its [official symbol](https://vercel.com/geist/brands/assets/vercel-symbol-black.svg)
from the [Vercel brand assets](https://vercel.com/geist/brands).

Coolify uses its [official logo](https://github.com/coollabsio/coolify/blob/main/public/coolify-logo.svg).
Dokploy uses its [official symbol](https://github.com/Dokploy/dokploy/blob/canary/apps/dokploy/public/logo.svg).
Their combined migration guide uses the existing Server or Docker flow.

The shared `AppLogo` renderer uses the bundled Railway and Vercel assets in website and dashboard.
Migration social previews embed these local provider marks without an external image request.
The marks belong to their respective brands.

Share cards also use pinned [Simple Icons 16.38.0](https://github.com/simple-icons/simple-icons/tree/16.38.0/icons) glyphs. The comment in each SVG identifies its source. Heroku comes from the same Devicon release as Railway. The Valkey, Open WebUI and pgAdmin images are their respective GitHub organization avatars. Radicale uses its upstream [v3.9.0 web interface mark](https://github.com/Kozea/Radicale/blob/v3.9.0/radicale/web/internal_data/css/logo.svg).
Dokku uses the [mark from its documentation](https://github.com/dokku/dokku/blob/b39ff6c3f92193f0b8c936a555eeaf8342a59b40/docs/assets/dokku-logo.svg).
