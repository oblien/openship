# Provider and database marks

Railway uses the [Devicon v2.16.0 mark](https://github.com/devicons/devicon/blob/v2.16.0/icons/railway/railway-original.svg)
with black fill for light surfaces; its shape is unchanged. PostgreSQL, MySQL and
MongoDB marks in `../app-logos` are unchanged from the same Devicon release.
These assets use the accompanying MIT license.

Vercel uses its [official symbol](https://vercel.com/geist/brands/assets/vercel-symbol-black.svg)
from the [Vercel brand assets](https://vercel.com/geist/brands).

The shared `AppLogo` renderer uses the same bundled assets in website and dashboard.
The marks belong to their respective brands.
