## Key concepts

A **project** connects source, configuration, and deployment history. Its **services** are the running
applications, workers, and databases. A **deployment** releases a version to a selected destination.

[Read the core concepts](/docs/getting-started/core-concepts) for organizations, environments,
control planes, runtimes, and domains.
