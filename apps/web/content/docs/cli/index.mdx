Use the CLI to deploy code, inspect releases, manage services, and operate a self-hosted installation.

## Install

```bash
npm install -g openship
openship --help
```

Node.js 22 or later is required. A local `npm install openship` also provides the command through `npx`.
The reference follows this repository; use `--help` to check your installed version. Native SDK mode and
SDK imports require the [preview package](/docs/api/sdk/installation) until its release is published.

## Connect and deploy

Start a [local installation](/docs/cli/run), or connect to an existing one:

```bash
openship login \
  --api-url https://ship.example.com \
  --dashboard-url https://ship.example.com \
  --context production

openship project list
openship init --project proj_123
openship deploy --watch
```

`login` opens the token settings page and asks for a personal access token. `init` links the current
directory to a project. `deploy --watch` submits a deployment and follows its progress.

## Scripts and application code

Use `openship --json project list` for machine-readable command output. See [automation](/docs/cli/automation)
for CI setup and exit handling. To call the same operations directly from JavaScript or TypeScript,
use the [Node.js SDK](/docs/api/sdk).
