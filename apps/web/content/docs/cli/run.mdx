---
title: Run and maintain Openship
description: Start a local installation, inspect it, and manage its lifecycle.
---

Use these commands on the machine that runs Openship. To manage an existing remote installation,
[configure a connection context](/docs/cli/access) instead.

## Start

```bash
openship
```

On a fresh machine, the interactive command guides setup. On an installed machine, it opens the
control panel or resumes an interrupted setup.

For direct startup:

```bash
openship up
openship status
openship open
```

`up` installs or starts a persistent service. `status` reports local service state and the active
context's API health. `open` opens the dashboard. Use `openship up --foreground` for an attached process.
See [all startup options](/docs/cli/reference/up), including Docker Compose configuration.

## Stop and update

```bash
openship stop
openship update
```

`stop` disables the service so it stays stopped across reboot. `update` updates the CLI and bundled
server. Read [updating Openship](/docs/guides/updating) before updating a production installation.

## Diagnose a problem

```bash
openship doctor
```

The [doctor reference](/docs/cli/reference/doctor) describes health and repair options. Local admin
account recovery uses [reset-admin-password](/docs/cli/reference/reset-admin-password).

## Installation commands compared

| Command | Purpose |
| --- | --- |
| `npm install -g openship` | Install the CLI globally. |
| `npm install openship` | Add the package to a Node project; SDK imports require an SDK-enabled release. |
| `openship install` | Download and install the desktop application. |
| `openship install cache` | Inspect or manage cached installation downloads. |
| `openship up` | Start the Openship API and dashboard as a local service. |
| `openship uninstall` | Remove local installation state and data; deployed apps are left running. |

See [installation](/docs/getting-started/installation) for platform requirements and
[command options](/docs/cli/reference#local-installation) before removing or repairing an installation.
