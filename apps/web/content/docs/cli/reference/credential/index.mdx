## openship credential

Manage stored registry and DNS credentials; reads return masked secrets

```text
openship credential|credentials [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`providers`](/docs/cli/reference/credential#openship-credential-providers) | Show supported providers and their required fields |
| [`list\|ls`](/docs/cli/reference/credential#openship-credential-list) | List stored credentials |
| [`get <id>`](/docs/cli/reference/credential#openship-credential-get) | Show one credential with secrets masked |
| [`create <file>`](/docs/cli/reference/credential#openship-credential-create) | Create a credential; required provider fields are validated by the engine |
| [`update <id> <file>`](/docs/cli/reference/credential#openship-credential-update) | Update selected credential fields without echoing secrets |
| [`verify <id>`](/docs/cli/reference/credential#openship-credential-verify) | Verify a credential against its provider |
| [`remove\|rm [options] <id>`](/docs/cli/reference/credential#openship-credential-remove) | Remove a stored credential |

## openship credential create

Create a credential; required provider fields are validated by the engine

```text
openship credential create [options] <file>
```

| Argument | Meaning |
| --- | --- |
| `file` | JSON object with provider, name, optional selector and values |

## openship credential get

Show one credential with secrets masked

```text
openship credential get [options] <id>
```

| Argument | Meaning |
| --- | --- |
| `id` | Credential ID |

## openship credential list

List stored credentials

```text
openship credential list|ls [options]
```

## openship credential providers

Show supported providers and their required fields

```text
openship credential providers [options]
```

## openship credential remove

Remove a stored credential

```text
openship credential remove|rm [options] <id>
```

| Argument | Meaning |
| --- | --- |
| `id` | Credential ID |

| Option | Meaning |
| --- | --- |
| `-y, --yes` | Skip confirmation |

## openship credential update

Update selected credential fields without echoing secrets

```text
openship credential update [options] <id> <file>
```

| Argument | Meaning |
| --- | --- |
| `id` | Credential ID |
| `file` | JSON credential patch |
