## openship project connections

Wire app outputs into a project's environment through the engine

```text
openship project connections [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`list <id>`](/docs/cli/reference/project/connections#openship-project-connections-list) | List this project's incoming app connections |
| [`candidates <id>`](/docs/cli/reference/project/connections#openship-project-connections-candidates) | List apps that can supply connection outputs |
| [`consumers <id>`](/docs/cli/reference/project/connections#openship-project-connections-consumers) | List projects consuming this project's outputs |
| [`create <id> <file>`](/docs/cli/reference/project/connections#openship-project-connections-create) | Connect one app output; redeploy to apply it |
| [`bundle <id> <file>`](/docs/cli/reference/project/connections#openship-project-connections-bundle) | Connect several app outputs atomically; redeploy to apply them |
| [`remove\|rm [options] <id> <connection>`](/docs/cli/reference/project/connections#openship-project-connections-remove) | Remove an app connection |

## openship project connections bundle

Connect several app outputs atomically; redeploy to apply them

```text
openship project connections bundle [options] <id> <file>
```

| Argument | Meaning |
| --- | --- |
| `id` | Target project ID |
| `file` | JSON connection bundle with sourceProjectId and items |

## openship project connections create

Connect one app output; redeploy to apply it

```text

```

| Argument | Meaning |
| --- | --- |
| `id` | Target project ID |
| `file` | JSON connection with sourceProjectId, outputId, envKey and optional mode |

| Argument | Meaning |
| --- | --- |

## openship project connections remove

Remove an app connection

```text
openship project connections remove|rm [options] <id> <connection>
```

| Argument | Meaning |
| --- | --- |
| `id` | Target project ID |
| `connection` | Connection ID |

| Option | Meaning |
| --- | --- |
| `-y, --yes` | Skip confirmation |
