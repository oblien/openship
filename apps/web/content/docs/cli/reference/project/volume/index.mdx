## openship project volume

Manage replicated project volumes and recoverable backups

```text
openship project volume [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`list <project>`](/docs/cli/reference/project/volume#openship-project-volume-list) | List volumes, resource versions and replica health |
| [`backups <project>`](/docs/cli/reference/project/volume#openship-project-volume-backups) | List volume backups available for recovery |
| [`create [options] <id> [file]`](/docs/cli/reference/project/volume#openship-project-volume-create) | Create a volume, optionally restored from a named backup |
| [`resize [options] <id> [file]`](/docs/cli/reference/project/volume#openship-project-volume-resize) | Grow a volume using its exact resource version |
| [`backup [options] <project> <volume>`](/docs/cli/reference/project/volume#openship-project-volume-backup) | Create a volume backup with an idempotent request ID |
| [`schedule [options] <id> [file]`](/docs/cli/reference/project/volume#openship-project-volume-schedule) | Set backup frequency and retention at a volume's current resource version |
| [`remove-backup [options] <id> [file]`](/docs/cli/reference/project/volume#openship-project-volume-remove-backup) | Delete a volume backup with explicit name confirmation |
| [`remove [options] <id> [file]`](/docs/cli/reference/project/volume#openship-project-volume-remove) | Delete an unused volume and its data, checking its name and resource version |
| [`events [options] <project>`](/docs/cli/reference/project/volume#openship-project-volume-events) | Stream health and operation progress |

## openship project volume backup

Create a volume backup with an idempotent request ID

```text
openship project volume backup [options] <project> <volume>
```

| Argument | Meaning |
| --- | --- |
| `project` | Project ID |
| `volume` | Volume name |

| Option | Meaning |
| --- | --- |
| `--request-id <id>` | Stable request ID for this backup (16–64 characters) |
