## openship server cluster storage

Manage replicated cluster storage and its backup destination

```text
openship server cluster storage [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`get [options] <id>`](/docs/cli/reference/server/cluster/storage#openship-server-cluster-storage-get) | Read storage status, disks and current sequence |
| [`setup [options] [file]`](/docs/cli/reference/server/cluster/storage#openship-server-cluster-storage-setup) | Configure replicated storage with explicit disks and capacity reservations |
| [`retry [options] <id>`](/docs/cli/reference/server/cluster/storage#openship-server-cluster-storage-retry) | retry storage at the reviewed sequence |
| [`remove [options] <id>`](/docs/cli/reference/server/cluster/storage#openship-server-cluster-storage-remove) | remove storage at the reviewed sequence |
| [`backup [options] <id> <destination>`](/docs/cli/reference/server/cluster/storage#openship-server-cluster-storage-backup) | Set the storage backup destination at its current sequence |
| [`events [options] <id>`](/docs/cli/reference/server/cluster/storage#openship-server-cluster-storage-events) | Stream storage progress |

## openship server cluster storage backup

Set the storage backup destination at its current sequence

```text
openship server cluster storage backup [options] <id> <destination>
```

| Argument | Meaning |
| --- | --- |
| `id` | Compute cluster ID |
| `destination` | Backup destination ID |

| Option | Meaning |
| --- | --- |
| `--sequence <number>` | Current sequence from storage get |
