## openship server

Manage self-hosted SSH servers

```text
openship server [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`list\|ls`](/docs/cli/reference/server#openship-server-list) | List servers in the active organization |
| [`add [options]`](/docs/cli/reference/server#openship-server-add) | Add a new server |
| [`rm\|remove <id>`](/docs/cli/reference/server#openship-server-rm) | Delete a server |
| [`test-connection\|test [options]`](/docs/cli/reference/server#openship-server-test-connection) | Test an SSH connection without saving it |
| [`check [options] <serverId>`](/docs/cli/reference/server#openship-server-check) | Run component health checks against a saved server |
| [`update [options] <serverId>`](/docs/cli/reference/server#openship-server-update) | Check for and apply native-module migrations (OpenResty, …) |
| [`install [options] <serverId>`](/docs/cli/reference/server#openship-server-install) | Install components on a server |
| [`install-session [sessionId]`](/docs/cli/reference/server#openship-server-install-session) | Inspect a server installation session |
| [`install-respond [options] <sessionId>`](/docs/cli/reference/server#openship-server-install-respond) | Respond to an installation prompt |
| [`rate-limit [options] <serverId>`](/docs/cli/reference/server#openship-server-rate-limit) | Read or update per-server OpenResty rate limiting |
| [`monitor <serverId>`](/docs/cli/reference/server#openship-server-monitor) | Stream live system stats (SSE) |
| [`ssh <serverId>`](/docs/cli/reference/server#openship-server-ssh) | Open an interactive SSH terminal (coming soon) |

## openship server add

Add a new server

```text
openship server add [options]
```

| Option | Meaning |
| --- | --- |
| `--host <host>` | SSH host / IP |
| `--name <name>` | Display name |
| `--port <port>` | SSH port (default: "22") |
| `--user <user>` | SSH user (default: "root") |
| `--auth-method <method>` | Auth method (password\|key\|agent) |
| `--password <password>` | SSH password (password auth) |
| `--key-path <path>` | Path to private key (key auth) |
| `--key-passphrase <passphrase>` | Private key passphrase |
| `--jump-host <host>` | SSH jump / bastion host |
| `--ssh-args <args>` | Extra raw ssh args |

## openship server check

Run component health checks against a saved server

```text
openship server check [options] <serverId>
```

| Option | Meaning |
| --- | --- |
| `-c, --component <name...>` | Limit to specific components |

## openship server install

Install components on a server

```text
openship server install [options] <serverId>
```

| Option | Meaning |
| --- | --- |
| `-c, --component <name...>` | Components to install (docker\|git\|edge\|rsync) |
| `--follow` | Stream install logs live (SSE) |

## openship server rate-limit

Read or update per-server OpenResty rate limiting

```text
openship server rate-limit [options] <serverId>
```

| Option | Meaning |
| --- | --- |
| `--rps <n>` | Requests per second (0 removes the limit) |
| `--burst <n>` | Burst allowance |
| `--whitelist <cidr...>` | CIDRs exempt from limiting |
