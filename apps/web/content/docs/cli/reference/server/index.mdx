## openship server add

Add a new server

```text
openship server add [options]
```

| Option | Meaning |
| --- | --- |
| `--host <host>` | SSH host / IP |
| `--name <name>` | Display name |
| `--port <port>` | SSH port (default: "22") |
| `--user <user>` | SSH user (default: "root") |
| `--auth-method <method>` | Auth method (password\|key\|agent) |
| `--password <password>` | SSH password (password auth) |
| `--password-file <file>` | SSH password file on this machine, or - for stdin |
| `--key-path <path>` | Private key path on the controller host |
| `--private-key-file <file>` | Read an SSH key from this machine, or - for stdin |
| `--key-passphrase <passphrase>` | Private key passphrase |
| `--jump-host <host>` | SSH jump / bastion host |
| `--ssh-transport <transport>` | SSH transport (direct\|cloudflare) |
| `--ssh-args <args>` | SSH connection tuning arguments |

