## openship launch

Set up this machine and open an app or repository's deployment wizard

```text
openship launch [options]
```

| Option | Meaning |
| --- | --- |
| `--app <id>` | Catalog app ID |
| `--repo <url>` | Public GitHub repository URL |
| `--branch <name>` | Repository branch (defaults to the repository's default) |
