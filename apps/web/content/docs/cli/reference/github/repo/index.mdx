## openship github repo

Browse and manage repositories available to this connection

```text
openship github repo [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`list [options]`](/docs/cli/reference/github/repo#openship-github-repo-list) | List repositories with explicit pagination and filters |
| [`get [options] <repository>`](/docs/cli/reference/github/repo#openship-github-repo-get) | Inspect a repository |
| [`create [options] <name>`](/docs/cli/reference/github/repo#openship-github-repo-create) | Create a GitHub repository |
| [`remove [options] <repository>`](/docs/cli/reference/github/repo#openship-github-repo-remove) | Permanently delete a GitHub repository |
| [`branches [options] <repository>`](/docs/cli/reference/github/repo#openship-github-repo-branches) | List branches and whether another page is available |
| [`clone-token <repository>`](/docs/cli/reference/github/repo#openship-github-repo-clone-token) | Print a short-lived clone credential; output contains a secret |
| [`detect [options] <repository>`](/docs/cli/reference/github/repo#openship-github-repo-detect) | Detect stack, build configuration and Compose services |
| [`files [options] <repository>`](/docs/cli/reference/github/repo#openship-github-repo-files) | List files at a repository path |
| [`tree [options] <repository>`](/docs/cli/reference/github/repo#openship-github-repo-tree) | List the repository tree |
| [`file [options] <repository> <path>`](/docs/cli/reference/github/repo#openship-github-repo-file) | Read a repository file and its revision |
| [`webhook`](/docs/cli/reference/github/repo#openship-github-repo-webhook) | Manage Openship deployment webhooks on a GitHub repository |

## openship github repo create

Create a GitHub repository

```text
openship github repo create [options] <name>
```

| Argument | Meaning |
| --- | --- |
| `name` | Repository name |

| Option | Meaning |
| --- | --- |
| `--owner <name>` | GitHub owner or organization |
| `--description <text>` | Repository description |
| `--public` | Create a public repository (default: private) |

## openship github repo list

List repositories with explicit pagination and filters

```text
openship github repo list [options]
```

| Option | Meaning |
| --- | --- |
| `--owner <name>` | Repository owner filter |
| `--org <name>` | List this GitHub organization's repositories |
| `--page <number>` | Page number |
| `--per-page <number>` | Page size |
| `--search <text>` | Repository search |
| `--visibility <type>` | Visibility filter (choices: "all", "public", "private") |
| `--sort <field>` | Sort order (choices: "updated", "name", "stars") |
