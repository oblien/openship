## openship analytics

Read project traffic, deployments and runtime resource measurements

```text
openship analytics [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`dashboard`](/docs/cli/reference/analytics#openship-analytics-dashboard) | Show totals for accessible projects and deployments |
| [`summary [options] <project>`](/docs/cli/reference/analytics#openship-analytics-summary) | Show request, visitor and bandwidth totals |
| [`traffic [options] <project>`](/docs/cli/reference/analytics#openship-analytics-traffic) | Show traffic totals and time buckets |
| [`periods [options] <project>`](/docs/cli/reference/analytics#openship-analytics-periods) | Read traffic time buckets |
| [`geo [options] <project>`](/docs/cli/reference/analytics#openship-analytics-geo) | Read traffic geography and request paths |
| [`deployments <project>`](/docs/cli/reference/analytics#openship-analytics-deployments) | Show deployment reliability and build duration |
| [`usage <project>`](/docs/cli/reference/analytics#openship-analytics-usage) | Read current project runtime usage |
| [`container <project>`](/docs/cli/reference/analytics#openship-analytics-container) | Read runtime container details |
| [`resources <project>`](/docs/cli/reference/analytics#openship-analytics-resources) | Read service measurements and destination capacity |
| [`history [options] <project>`](/docs/cli/reference/analytics#openship-analytics-history) | Read historical CPU, memory and network usage |
| [`paths <project> <state>`](/docs/cli/reference/analytics#openship-analytics-paths) | Enable or disable collection of request paths |
| [`watch [options] <project>`](/docs/cli/reference/analytics#openship-analytics-watch) | Stream live project resource measurements |
| [`server`](/docs/cli/reference/analytics#openship-analytics-server) | Inspect traffic for a domain handled by a particular server |
