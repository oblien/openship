## openship domain

Manage custom domains, DNS verification, and SSL certificates

```text
openship domain [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`list [options]`](/docs/cli/reference/domain#openship-domain-list) | List a project's custom domains |
| [`add [options] <hostname>`](/docs/cli/reference/domain#openship-domain-add) | Add a custom domain and route it on the next deploy |
| [`preview <hostname>`](/docs/cli/reference/domain#openship-domain-preview) | Preview the DNS records a hostname would need (no changes saved) |
| [`verify [options] <id>`](/docs/cli/reference/domain#openship-domain-verify) | Run DNS verification for a domain |
| [`primary <id>`](/docs/cli/reference/domain#openship-domain-primary) | Make a domain the project's primary hostname |
| [`records <id>`](/docs/cli/reference/domain#openship-domain-records) | Show the DNS records for an existing domain |
| [`renew <id>`](/docs/cli/reference/domain#openship-domain-renew) | Renew the SSL certificate for a domain |
| [`verify-ssl <id>`](/docs/cli/reference/domain#openship-domain-verify-ssl) | Recheck that a domain's SSL certificate is issued and valid (no reissue) |
| [`renew-all`](/docs/cli/reference/domain#openship-domain-renew-all) | Renew SSL for every near-expiry domain in your organization |
| [`dns`](/docs/cli/reference/domain/dns#openship-domain-dns) | Plan and apply provider-managed DNS records |
| [`get <id>`](/docs/cli/reference/domain#openship-domain-get) | Show a domain and its routing configuration |
| [`remove\|rm [options] <id>`](/docs/cli/reference/domain#openship-domain-remove) | Remove a domain and its managed route |
| [`upload-cert [options] <id>`](/docs/cli/reference/domain#openship-domain-upload-cert) | Install a manual certificate through the shared hostname and key validation |
| [`verify-pending [options]`](/docs/cli/reference/domain#openship-domain-verify-pending) | Retry eligible pending domains within the selected organization |

## openship domain add

Add a custom domain and route it on the next deploy

```text
openship domain add [options] <hostname>
```

| Argument | Meaning |
| --- | --- |
| `hostname` | Domain hostname (e.g. app.example.com) |

| Option | Meaning |
| --- | --- |
| `-p, --project <id>` | Project ID to attach the domain to |
| `--primary` | Mark this domain as the project's primary (default: false) |

```text

```

| Argument | Meaning |
| --- | --- |
| `id` | Domain ID |

## openship domain list

List a project's custom domains

```text
openship domain list [options]
```

| Option | Meaning |
| --- | --- |
| `-p, --project <id>` | Project ID to list domains for |
| `--limit <number>` | Show one page of at most this many domains, ordered by hostname |
| `--cursor <cursor>` | Continue from the cursor printed by the previous page |

## openship domain upload-cert

Install a manual certificate through the shared hostname and key validation

```text

```

| Argument | Meaning |
| --- | --- |
| `id` | Domain ID |

| Option | Meaning |
| --- | --- |
| `--cert <file>` | PEM certificate chain file |
| `--key <file>` | PEM private key file |

## openship domain verify

Run DNS verification for a domain

```text
openship domain verify [options] <id>
```

| Argument | Meaning |
| --- | --- |
| `id` | Domain ID |

| Option | Meaning |
| --- | --- |
| `--force` | Recheck an already-verified hostname |
| `--follow` | Stream DNS and certificate progress |
| `--timeout <ms>` | Stop following after this deadline |

## openship domain verify-pending

```text

```

| Option | Meaning |
| --- | --- |
| `--limit <number>` | Maximum domains to inspect |
| `--min-age <minutes>` | Minimum pending age in minutes |
