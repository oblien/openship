## openship job

Manage self-hosted jobs, schedules, and run logs

```text
openship job|jobs [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`list`](/docs/cli/reference/job#openship-job-list) | List system and custom jobs |
| [`get <key>`](/docs/cli/reference/job#openship-job-get) | Show a job's configuration and recent runs |
| [`create [options]`](/docs/cli/reference/job#openship-job-create) | Create a scheduled command or saved workflow job |
| [`update [options] <key>`](/docs/cli/reference/job#openship-job-update) | Update a job; built-ins accept schedule and enabled changes |
| [`delete\|rm [options] <key>`](/docs/cli/reference/job#openship-job-delete) | Delete a custom job (system jobs cannot be deleted) |
| [`run [options] <key>`](/docs/cli/reference/job#openship-job-run) | Run a job now; custom jobs return a run ID |
| [`runs [options] <key>`](/docs/cli/reference/job#openship-job-runs) | List a job's run history |
| [`logs [options] <runId>`](/docs/cli/reference/job#openship-job-logs) | Show stored run output, or the full run in JSON mode |
| [`events`](/docs/cli/reference/job#openship-job-events) | List event types available as job triggers |
| [`backup-schedules`](/docs/cli/reference/job#openship-job-backup-schedules) | List scheduled backups with their next and last runs |

## openship job backup-schedules

List scheduled backups with their next and last runs

```text
openship job backup-schedules [options]
```

## openship job create

Create a scheduled command or saved workflow job

```text
openship job create [options]
```

| Option | Meaning |
| --- | --- |
| `--name <name>` | Job label |
| `--server <id>` | Target server ID |
| `--command <command>` | Shell command to execute on the server |
| `--schedule <type>` | Schedule type (choices: "recurring", "once", "manual") |
| `--cron <expression>` | Five-field cron expression |
| `--at <iso>` | Run time for a once schedule |
| `--file <path>` | JSON API body (workflowId/inputs or command settings); flags override file values |

## openship job delete

Delete a custom job (system jobs cannot be deleted)

```text
openship job delete|rm [options] <key>
```

| Option | Meaning |
| --- | --- |
| `-y, --yes` | Confirm deletion |

Show stored run output, or the full run in JSON mode

```text
openship job logs [options] <runId>
```

| Option | Meaning |
| --- | --- |
| `-f, --follow` | Stream output until completion; exit nonzero on failure |

## openship job update

Update a job; built-ins accept schedule and enabled changes

```text
openship job update [options] <key>
```

| Option | Meaning |
| --- | --- |
| `--name <name>` | Job label |
| `--server <id>` | Target server ID |
| `--command <command>` | Shell command to execute on the server |
| `--schedule <type>` | Schedule type (choices: "recurring", "once", "manual") |
| `--cron <expression>` | Five-field cron expression |
| `--at <iso>` | Run time for a once schedule |
| `--file <path>` | JSON API body (workflowId/inputs or command settings); flags override file values |
| `--enabled` | Enable the job |
| `--no-enabled` | Disable the job |
