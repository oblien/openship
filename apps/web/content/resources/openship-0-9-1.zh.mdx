OpenShip 0.9.1 改进了部署的步骤：选择应用、配置其运行时、返回保存的设置以及准备下一个版本。

## 安装前探索

通过[公共应用目录](/apps)]，您无需先打开仪表板即可浏览后端、数据库、发布工具和自动化。按类别搜索或过滤，然后打开应用程序以查看其功能、包含的服务和要求。

安装继续通过现有的设置流程。应用程序和计划链接通过登录和验证保留其目的地，并且确认的安装设置可以在结帐后恢复。

## 更慎重的运行时配置

生成的 PHP 版本通过运行时版本设置支持 PHP 8.3 和 8.4。 Docker 源版本还公开了高级生产映像覆盖。配方在激活之前检查运行时功能和兼容性，保留映像回滚会保留原始运行时配置。

手动 Docker 重新部署刷新可变注册表标记，同时保留本地构建和固定的回滚工件。替换映像是在服务激活之前准备的。失败的准备会使当前容器继续运行；后续多业务切换仍保持顺序。

## 无需重新创建所有内容即可恢复

已保存的云服务器链接具有更清晰的重新连接操作以及针对帐户不匹配和临时故障的指导。当现有的 Web 邮件应用程序的邮件注册丢失项目链接时，也可以重新连接，从而重用其项目和持久存储。

迁移现在保留仅路由选定路径的域。精确路由和前缀路由仍然附加到其服务，并且不匹配的请求保持不匹配。

## 工作流程和语言改进

独立操作工作流程可以保存有效的自定义 YAML，并为缺少的名称、运行程序、验证或访问设置提供更清晰的指导。连接的桌面和自托管实例将云工作流程和运行器操作转发到所属的云实例。

俄语加入了仪表板语言，网络邮件通过其事件流接收实时收件箱更新。
