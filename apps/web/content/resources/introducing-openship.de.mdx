Heute veröffentlichen wir OpenShip – eine Bereitstellungsplattform, die Sie auf Ihren eigenen Servern ausführen können.

## Warum wir das gebaut haben

Cloud-Plattformen wie Vercel und Netlify eignen sich hervorragend für den Einstieg. But as your app grows, so does the bill. Gemessene CPU, Preise pro Arbeitsplatz, Bandbreitenbeschränkungen – das summiert sich schnell. Und wenn Sie gehen wollen, stellen Sie fest, dass Ihre Infrastruktur an ihre proprietären Systeme gebunden ist.

We wanted something different:

- **Zuerst selbst gehostet** – Auf jedem Linux Server ausführen. Ein VPS für 20 US-Dollar pro Monat übernimmt die Kosten, die auf verwalteten Plattformen über 200 US-Dollar betragen.
- **Open source** - Apache-2.0 licensed. No black boxes, no vendor lock-in.
- **KI-unterstützt** – Framework-Erkennung, Build-Optimierung und Konfiguration werden automatisch durchgeführt.

## Was Sie bereitstellen können

OpenShip unterstützt jeden Stack, der in einem Container ausgeführt wird:

- **Frontend-Frameworks** – Next.js, Nuxt, SvelteKit, Astro, Remix
- **Backend** – Node.js, Python, Go, Rust, Ruby, PHP
- **Datenbanken** – Postgres, MySQL, Redis, MongoDB
- **Full-Stack** – Multi-Service-Apps mit gemeinsamer Vernetzung

## Erste Schritte

```bash
curl -fsSL https://get.openship.io | sh
cd your-project
openship deploy
```

Drei Befehle. Das ist es.
