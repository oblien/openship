当您运行 `openship deploy` 时，在您的应用上线之前会发生很多事情。以下是人工智能构建系统的工作原理。

## 步骤1：框架检测

OpenShip 扫描您的项目以获取信号：

- `package.json` 脚本和依赖项
- 配置文件（`next.config.js`、`nuxt.config.ts`、`Cargo.toml` 等）
- Docker文件存在
- 目录结构模式

这会产生置信度评分的框架匹配。如果 OpenShip 以 95% 的置信度检测到 Next.js，它将使用 Next.js 构建管道。如果存在 Docker 文件，则会直接使用该文件。

## 步骤 2：配置生成

根据检测到的框架，OpenShip 生成：

- **构建命令** - `npm run build`、`go build` 等。
- **启动命令** - `npm start`、`./server` 等。
- **端口映射** - 检测您的应用程序侦听的端口
- **环境变量** - 根据框架约定建议所需的变量

您可以覆盖 `openship.json` 中的任何一项。

## 步骤 3：构建优化

AI层优化构建：

- **层缓存** - 依赖层与源代码分开缓存
- **多阶段构建** - 生产映像排除开发依赖项
- **并行构建** - 多服务项目同时构建

## 步骤 4：健康检查

部署后，OpenShip 验证：

- 容器启动成功
- 健康检查端点响应
- SSL 已配置且有效

如果任何检查失败，部署将自动回滚。

## 接下来是什么

我们正在致力于人工智能驱动的诊断 - 当构建失败时，OpenShip 将分析错误并提出修复建议。敬请关注。
