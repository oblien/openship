本日、私たちは OpenShip をオープンソース化します。これは、独自のサーバー上で実行できる展開プラットフォームです。

## これを構築した理由

Vercel や Netlify などのクラウド プラットフォームは、始めるのに最適です。ただし、アプリが成長するにつれて、請求額も増加します。従量制の CPU、シートごとの価格設定、帯域幅の上限 - これらはすぐに加算されます。そして、退職したいと思ったとき、自分のインフラストラクチャが彼らの独自のシステムにロックされていることに気づきます。

私たちは何か違うものを望んでいました。

- **最初はセルフホスト** - 任意の Linux サーバーで実行します。月額 20 ドルの VPS は、マネージド プラットフォームで 200 ドル以上かかるものを処理します。
- **オープンソース** - Apache-2.0 のライセンスが付与されています。ブラックボックスやベンダーロックインはありません。
- **AI 支援** - フレームワークの検出、ビルドの最適化、構成が自動的に処理されます。

## デプロイできるもの

OpenShip は、コンテナ内で実行される任意のスタックをサポートします。

- **フロントエンド フレームワーク** - Next.js、Nuxt、SvelteKit、Astro、Remix
- **バックエンド** - Node.js、Python、Go、Rust、Ruby、PHP
- **データベース** - Postgres、MySQL、Redis、MongoDB
- **フルスタック** - 共有ネットワークを備えたマルチサービス アプリ

## はじめに

```bash
curl -fsSL https://get.openship.io | sh
cd your-project
openship deploy
```

コマンドは 3 つ。それでおしまい。
